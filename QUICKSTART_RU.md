# Быстрый запуск

1. Установи Python 3.9 или новее.
2. Сохрани `fix_fb2_metadata.py` в удобный каталог.
3. Сначала выполни проверку без изменений:

   ```bash
   python3 fix_fb2_metadata.py "/путь/к/библиотеке"
   ```

4. Проверь строки `DRY-RUN`, `OK` и `ERROR` в выводе. Подробности ошибок смотри в `fix_fb2_metadata_errors.log` рядом со скриптом.
5. Если результат проверки подходит, примени исправления:

   ```bash
   python3 fix_fb2_metadata.py "/путь/к/библиотеке" --apply
   ```

6. Оригиналы изменённых книг сохраняются в `_fb2_backup/` внутри корня библиотеки. Перед повторным запуском проверь этот каталог: существующие резервные копии не перезаписываются.

Важно: скрипт исправляет только числовые XML-ссылки внутри `<description>` и не обрабатывает содержимое ZIP-архивов.
